# پروژه VEX Client (پیش‌نمایش اندروید)

این پروژه یک پوستهٔ اندرویدی ساده است که رابط HTML داخل WebView را اجرا می‌کند. سورس رابط در `app/src/main/assets/index.html` قرار دارد.

## قابلیت‌های فعلی
- رابط تیره با برند VEX
- اجرا به‌صورت اپ اندرویدی
- ورودی اولیه برای لینک‌های `vless://`، `vmess://` و `trojan://`
- بدون نیاز به نصب IDE روی گوشی، با ساخت ابری GitHub Actions

## محدودیت مهم
این پروژه **موتور VPN ندارد**. واردکردن/تشخیص اولیه لینک، به معنی اتصال واقعی نیست. دکمه اتصال فعلاً نمایشی است. برای اتصال واقعی باید یک موتور سازگار، مجوز `VpnService`، چرخه اتصال/قطع، مدیریت خطا و بررسی مجوزهای متن‌باز به‌صورت جداگانه پیاده‌سازی و آزمایش شوند. این APK را VPN عملیاتی فرض نکن.

## ساخت APK رایگان از گوشی با GitHub Actions

1. فایل ZIP را از حالت فشرده خارج کن.
2. در مرورگر گوشی وارد https://github.com/new شو و یک مخزن جدید بساز؛ مثلاً `VEX-Android`. می‌توانی مخزن را Private نگه داری.
3. داخل مخزن، فایل‌های این پروژه را بارگذاری کن؛ ساختار پوشه‌ها باید دقیقاً حفظ شود. راحت‌ترین روش معمولاً GitHub در مرورگر با گزینه Upload files است؛ اگر آپلود کل پوشه‌ها در مرورگر دشوار بود، از GitHub Desktop روی کامپیوتر لازم نیست استفاده کنی، و می‌توانی از ابزار Git موبایلی دلخواه استفاده کنی.
4. بعد از commit کردن فایل‌ها، وارد تب **Actions** شو. گردش کار `Build VEX APK` باید شروع شود؛ اگر نه، آن را باز کن و **Run workflow** بزن.
5. صبر کن تا کار تمام شود و وضعیت سبز شود.
6. در صفحه اجرای workflow، بخش **Artifacts** را باز کن و `VEX-debug-APK` را دانلود کن.
7. ZIP مربوط به Artifact را باز کن؛ فایل `app-debug.apk` داخل آن است. آن را نصب کن.

## ساخت محلی (اختیاری)
در محیطی که Java 17 و Gradle 8.9 نصب دارد، از ریشه پروژه اجرا کن:

```bash
gradle assembleDebug
```

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## امنیت و حریم خصوصی
- کانفیگ‌های VPN حاوی اطلاعات حساس‌اند؛ آن‌ها را در مخزن GitHub یا issueها قرار نده.
- APK ساخته‌شده debug است و برای انتشار عمومی، امضای release و بررسی امنیت لازم دارد.
- هیچ هزینه‌ای برای این سورس یا GitHub Actions عمومی تضمین نمی‌شود؛ سهمیه و محدودیت حساب GitHub ممکن است تغییر کند.
